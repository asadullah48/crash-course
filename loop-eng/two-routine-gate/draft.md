# loop-eng/ Summary

The `loop-eng/` directory holds the Loop Engineering crash-course projects: `bonus` (three extra loop patterns — retry loops, bounded loops, and human-in-the-loop approval gates — that fill gaps outside the official numbered concepts), `break-it-on-purpose` (a Project 3 loop deliberately sabotaged to practice diagnosing failures and measuring token cost from the spine alone), `daily-loop` (the capstone project combining heartbeat, worktree, skill, maker-checker, connector, and spine into one unattended daily loop), `doorbell` (an event-driven loop that stays idle until a code change triggers a review, rather than running on a timer), `doorbell-loop` (an in-progress event-driven checkpoint project setting up GitHub App-triggered PR review workflows), `iss-loop` (an in-session loop that polls the ISS's location once a minute while you watch), `morning-brief` (an unattended scheduled loop that reports repo changes since its last run using a `progress.md` file as memory), `paper-watch` (a scheduled watch loop that shows new arXiv papers on a topic, skipping ones already seen via a memory file), `portfolio-starter` (a spec-driven exercise where you build a personal portfolio site by defining "done" and letting a loop reach it, with no worked example provided), `sky-watch` (an unattended scheduled loop that checks for near-Earth asteroids each morning and reports anything worth worrying about), and `watch-loop` (an in-session loop that monitors a background task and reports only once it finishes).
